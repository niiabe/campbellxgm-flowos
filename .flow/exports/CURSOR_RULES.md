# Cursor IDE Rules — CampelXGM

## Project Context
This project follows a structured FlowOS blueprint. Follow the phase-based execution model.

## Development Rules
1. Always read the current phase file before starting work
2. Update project_state.md after completing each phase
3. Never modify the blueprint files directly
4. Log all decisions in memory/decisions.md
5. Complete phases in order

## Stack Preference
- framework: React Native
- backend: Firebase
- database: SQLite

## Testing
Write tests alongside implementation for each phase.
