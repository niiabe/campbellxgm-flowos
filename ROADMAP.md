# CampbellXGM - Feature Roadmap

## Free Features (Current Release)

| Feature | Status | Description |
|---------|--------|-------------|
| Aggressive App Freezing | ✅ Done | Force-stop background apps via Device Owner/Admin/Accessibility |
| DND Mode | ✅ Done | Block calls/notifications during gameplay (allows media) |
| Keep Screen Awake | ✅ Done | Prevent screen from turning off |
| Auto-Brightness Lock | ✅ Done | Lock brightness during gameplay |
| FPS Counter | ✅ Done | Real-time FPS overlay toggleable in settings |
| Network Boost | ✅ Done | Lock WiFi band, disable background data, prioritize gaming traffic |
| Battery Profile | ✅ Done | Switch to performance mode, disable battery saver |
| Auto-Start Game Mode | ✅ Done | Detect game launch and auto-activate game mode |
| CPU/GPU Tuner | ✅ Done | Adjust performance governor (Device Owner only) |
| Notification Filter | ✅ Done | Allow specific contacts/apps to bypass DND |
| Cool-down Mode | ✅ Done | Lower performance when device overheats |
| DNS Provider | ✅ Done | Switch between Google, Cloudflare, OpenDNS, Quad9, AdGuard |
| Storage Cleaner | ✅ Done | Clear game cache and temp files before launch to free storage |

## Pro Features (Paid - Future Release)

| Feature | Description |
|---------|-------------|
| Ping Monitor | Real-time ping overlay showing latency to game servers |
| Game Server Selector | Ping multiple game servers and show which has lowest latency |
| Data Saver Per-App | Block specific apps from using data during gameplay |
| Real-time Hardware HUD | A unified floating widget displaying live RAM, CPU, and Battery temperature alongside FPS |
| Battery Drain Tracker | Show power consumption rate during gaming sessions |
| Individual Game Profiles | Per-game engine settings (different DND levels, DNS, optimizations, etc.) |
| Custom Crosshair Overlay | Customizable aiming reticle for FPS games |
| Session Timer | Track play time, break reminders |
| Notification Manager | Allow specific contacts/apps to bypass DND |
| Screen Recorder | Built-in game recording with optional face cam overlay |
| Macro Recorder | Record and replay touch sequences for repetitive game actions |
